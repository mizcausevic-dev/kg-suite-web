Install

One pinned entry. Local by default.

Add this published version to your MCP client config (Claude Desktop, Cursor, or another MCP client), then restart. The server exposes 75 tools; optional live audit calls need separate configuration.

{
  "mcpServers": {
    "kinetic-gain": {
      "command": "npx",
      "args": ["-y", "mcp-kinetic-gain@0.10.0"]
    }
  }
}
  • stdio transport. Runs locally over stdio. Nothing to host, no endpoint to expose.
  • Local tools need no key. Optional live audit-stream tools require AUDIT_STREAM_URL and AUDIT_STREAM_TOKEN.
  • One config entry. A single mcpServers block wires in all 75 tools.
  • Preview boundary. This published server does not intercept downstream calls or enforce buyer authorization. URL fetch tools can contact user-supplied public origins.
  • AGPL-3.0. Open source. Live on npm and the MCP Registry.
