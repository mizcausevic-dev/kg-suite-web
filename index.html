Explain this page:

Kinetic Gain is a set of open JSON specs that let an AI vendor declare what a system is, what it refuses, what evidence backs its claims, and what happens when it fails, so procurement teams, compliance reviewers, and other AI agents can verify it automatically instead of taking your word for it.

Kinetic Gain gives AI vendors a standard, written way to state what their system actually does, what it won't do, what proof backs up its claims, and what happens if it breaks. That means the people who have to sign off on using it, procurement, compliance, security, can check those claims themselves instead of just trusting a sales pitch.

Think of it like a nutrition label, but for AI. Instead of a company just telling you "our AI is safe and accurate," Kinetic Gain gives them a standard form to fill out that says exactly what the AI can do, what it refuses to do, and what proof they have for their claims. Anyone can check that form against the real AI and see if the company was telling the truth.

02 - Overview

The core layer

Each spec carries a top-level <name>_version field. The MCP server exposes fetch / validate / inspect / cross-spec-join tools for all twelve specs. The eleven regulated-vertical 6-packs, HealthTech, EdTech, PropTech, InsurTech, HR Tech, FinTech, GovTech, LegalTech, EnergyTech, DefenseTech, RetailTech, fan the same six canonical artifact shapes across 66 sibling spec repos; see /verticals/ for the full extension layer.

03 - Entry points

Two front doors

VALIDATOR - web

validator.kineticgain.com

Paste any Suite JSON in the browser and get a procurement-grade validation report. Auto-detects which of the twelve specs the document belongs to via its *_version field, then validates against the canonical JSON Schema 2020-12.

  • 12 schemas bundled - no network at validation time
  • Companion: React visualizer with 11 currently supported document types; the MCP server covers all 12 specs
